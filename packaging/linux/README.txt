Sage Study for Linux

To run it, double-click SageStudy in this folder, or run ./SageStudy from a terminal.

It opens in your default browser unless a desktop window library is available. It works the same either way, and
everything still stays on your computer.

You also need your own Claude Code and a Claude plan that includes it. The app walks you through this when it opens.

To remove it, delete this folder. Your study data is in ~/.local/share/SageStudy; delete that too if you don't want to keep it.

Sage Study is unofficial and isn't affiliated with or endorsed by Anthropic.
